- Prepared with `prepare-bodyparts.py`, `obj2gltf` and glTF Transform.
- SHA-256: `79a9e6839292929b5ae15fc0b08369c10b0007ba2b84a5793de7c1462678242f`

The model contains eight named meshes: five lobe groups, trachea, right main bronchus and left main
bronchus. It is a technical fixture, not a clinically validated anatomy model.
