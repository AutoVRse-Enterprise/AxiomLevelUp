# Showcase image provenance

The SVG files in this directory are original synthetic illustrations created for the Axiom Level Up
runtime showcase. They do not depict patient data, are not derived from third-party media and may
be distributed with this project.

- `cell-map.svg`: stylized cell field for zoom and hotspot demonstrations.
- `tissue-control.svg`: abstract control tissue for image comparison.
- `tissue-treated.svg`: abstract treated tissue for image comparison.
